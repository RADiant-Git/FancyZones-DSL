## 🎯 Зачем этот плагин?

Стандартный визуальный редактор макетов в **Microsoft PowerToys FancyZones** требует большого количества ручных действий мышью: открытие настроек, захват разделителей, подгонка пикселей.

**FancyZones DSL** приносит скорость и гибкость тайлинговых оконных менеджеров (i3, bspwm, Hyprland) в Windows:
1. Нажмите горячую клавишу Flow Launcher (по умолчанию `Alt + Space`).
2. Введите формулу разметки экрана (например, `fz 1(2)+2 -s 8 Work`).
3. Нажмите `Enter` — сетка мгновенно скомпилирована, сохранена в PowerToys и применена к монитору.

## ✨ Возможности

- 📐 **Потоковый сплит**: деление на колонки (`+`) или строки (`/`) с внутренними подуровнями.
- ⚖️ **Относительные веса**: распределение ширины/высоты блоков через коэффициенты `(w)`.
- 🎛️ **Кастомные пропорции внутри блоков**: нарезка зон через `{h1:h2:...}`.
- 🧩 **2D-матрицы**: свободное зонирование через буквенную координатную сетку (`A A B | C D B`).
- ⚡ **Быстрые сетки**: создание равномерных сеток за секунду (`2x2`, `3x4`, `2`).
- 🔄 **Умный буфер `Temp`**: макеты без имени перезаписывают единый слот `Temp`, не засоряя список сеток в PowerToys.
- 🔍 **Поиск и переключение**: быстрый выбор и применение уже существующих макетов из памяти.
- ⌨️ **Привязка хоткеев**: назначение системных комбинаций `Win + Ctrl + Alt + [0-9]` на лету флагом `-k`.

## 📦 Установка

### Требования
1. **[PowerToys](https://github.com/microsoft/PowerToys)** (включенный модуль FancyZones).
2. **[Flow Launcher](https://www.flowlauncher.com/)** (версия 1.11+).
3. **Python 3.8+** (обычно поставляется вместе с Flow Launcher).

### Ручная установка
1. Скачайте репозиторий или склонируйте его в папку плагинов Flow Launcher:
   ```cmd
   cd "%APPDATA%\FlowLauncher\Plugins"
   git clone https://github.com/your-username/FansyZonesControl.git FancyZonesDSL
   ```
2. Если зависимости не предустановлены, выполните:
   ```cmd
   cd FancyZonesDSL
   pip install -r requirements.txt -t ./lib
   ```
3. Перезапустите Flow Launcher (`Ctrl + R` в строке поиска лаунчера).

## 📖 Справочник по синтаксису (DSL)

### Общая формула команды:
```text
fz <Геометрия> [-s <px>] [-k <0-9>] [-m <id>] [Имя]
```

- **`Геометрия`** — описание расположения зон (колонки, строки, матрица или сетка).
- **`-s <px>`** — отступ (gap) между окнами в пикселях (по умолчанию `16`).
- **`-k <0-9>`** — привязать хоткей быстрого переключения `Win + Ctrl + Alt + [0-9]`.
- **`-m <id>`** — монитор (`0`, `1`, `all`). По умолчанию — активный монитор.
- **`[Имя]`** — название макета. Если опущено — используется и перезаписывается макет **`Temp`**.

---

### 1. Кирпичик сплита: `Внутри(Снаружи)`

Каждый элемент в цепочке колонок (`+`) или строк (`/`) задается по единому правилу:

| Запись | Внутренние зоны | Внешний вес | Описание |
| :--- | :---: | :---: | :--- |
| `1` | 1 зона | 1 | Обычный цельный блок базового размера. |
| `1(2)` | 1 зона | 2 | Цельный блок двойной ширины (или высоты). |
| `2` | 2 равные зоны | 1 | Две равные зоны в стандартном блоке. |
| `2(3)` | 2 равные зоны | 3 | Две равные зоны в блоке тройной ширины. |
| `{3:1}` | 2 зоны (75% / 25%) | 1 | Две неравные зоны по вертикали. |
| `{3:1}(2)` | 2 зоны (75% / 25%) | 2 | Две неравные зоны в блоке двойной ширины. |

---

### 2. Режимы геометрии

#### Колонки (`+`)
Делит экран по вертикали на столбцы слева направо:
```text
fz 1 + 2 + 1
```
*3 колонки: по краям по 1 окну, по центру 2 окна друг над другом.*

#### Строки (`/`)
Делит экран по горизонтали на полосы сверху вниз:
```text
fz 1 / 3 / 1
```
*3 строки: верхний бар, центр из 3 окон в ряд, нижний бар.*

#### Буквенная матрица (`|` или `;`)
Свободная 2D-раскладка. Смежные одинаковые символы объединяются в единые зоны:
```text
fz A A B | C D B
```
*Широкая область `A` сверху, два окна `C` и `D` под ней, высокий сайдбар `B` справа на всю высоту.*

#### Быстрая сетка (`MxN` или `N`)
Равномерная таблица без ручных делений:
- `fz 2x3` — 2 строки на 3 колонки (6 окон).
- `fz 2` — квадрат $2 \times 2$ (4 окна).

## 💡 Примеры из реальной жизни

| Задача | Команда |
| :--- | :--- |
| **Master-Stack (Кодинг)**<br>Слева 60% окно кода, справа два вспомогательных | `fz 1(3)+2(2) -s 8 Code` |
| **Ультраширокий экран (20% - 60% - 20%)**<br>Центр разделен на две рабочие области | `fz 1 + 2(3) + 1 -s 10 Ultrawide` |
| **Асимметричный фокус**<br>Центральный стек 75%/25% двойной ширины | `fz 1 + {3:1}(2) + 1(2) -s 4 Focus` |
| **Сетка без зазоров (встык)**<br>Временная сетка $2 \times 2$ без отступов | `fz 2x2 -s 0` |
| **Трансляция / Стриминг**<br>Верхний чат, центр под игру, сайдбар под дашборд | `fz A A B \| C D B Stream` |
| **Привязка к хоткею**<br>Создать макет и повесить на `Win+Ctrl+Alt+1` | `fz 1(2)+2 -k 1 DevMain` |

## 🔍 Поиск и контекстное меню

- **Просмотр всех макетов:** введите `fz` без параметров, чтобы увидеть список всех сохраненных макетов.
- **Поиск по имени:** начните вводить имя существующего макета (например, `fz Code`), чтобы быстро переключиться на него клавишей `Enter`.
- **Удаление макета:** выделите любой сохраненный макет в списке, нажмите `Shift + Enter` (или ПКМ) и выберите **«Удалить макет»**.

## 🛠️ Архитектура

Плагин взаимодействует с системой напрямую, без эмуляции пользовательского ввода:

```text
[Flow Launcher UI]
       │ (JSON-RPC)
       ▼
   main.py ──► fz_compiler.py (Математический расчет долей через fractions.Fraction)
       │
       ▼
  fz_backend.py
       ├──► %LOCALAPPDATA%/Microsoft/PowerToys/FancyZones/custom-layouts.json
       └──► FancyZonesCLI.exe s <uuid>
```

- **Расчет координат:** границы внутренних зон высчитываются через модуль `fractions.Fraction`, что гарантирует целочисленные доли сетки FancyZones (база 10 000 долей) без погрешностей округления с плавающей точкой.
- **Переключение сеток:** задействует встроенный системный интерфейс `FancyZonesCLI.exe`, благодаря чему макеты применяются моментально без перезапуска PowerToys.

## ❓ Частые вопросы (FAQ)

<details>
<summary><b>Что происходит с макетом Temp?</b></summary>
Макет <code>Temp</code> имеет постоянный зарезервированный системный идентификатор (GUID). При каждом вводе команды без явного имени (например, <code>fz 1+2</code>) макет <code>Temp</code> обновляется на месте, сохраняя активную геометрию на экране и не создавая мусорных копий в вашей базе.
</details>

<details>
<summary><b>Где плагин ищет FancyZonesCLI.exe?</b></summary>
Плагин проверяет системный <code>PATH</code>, стандартную папку <code>C:\Program Files\PowerToys\</code>, а также пользовательские каталоги установки в <code>%LOCALAPPDATA%</code>.
</details>
